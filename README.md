# Arte Digital — Juan Manuel Hernández Morey

Selección de pinturas e ilustraciones personales creadas en técnica digital. La herramienta usada en la mayoría del trabajo es Krita
Estas obras exploran la luz, la identidad, el retrato simbólico y los escenarios con carga narrativa.

🎨 Temáticas frecuentes:
- Ciencia ficción emocional
- Retratos con carácter
- Arquitectura imaginaria
- Iconografía poética

Las imágenes pueden visualizarse en alta resolución y descargarse para uso personal.
